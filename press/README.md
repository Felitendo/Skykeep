# Skykeep press kit

Everything you need to write about Skykeep, free to use in articles, videos and reviews.

**Skykeep** brings iCloud Notes, Reminders, Calendar, Contacts, iCloud Drive and Photos to
Linux and Windows as six desktop apps with one sign-in. It's free and open source (GPL-3.0),
and made by one person, me, [Yashwanth Kamireddi](https://github.com/YashwanthKamireddi).
